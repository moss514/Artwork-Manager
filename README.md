# 🎨 MOSS 画作管理器

> 一款基于 Tauri v2 + Vanilla JS 构建的轻量级、纯本地画作与笔记管理桌面应用。
> 图标致敬经典 —— *It's Hero Time!*

## 📥 下载与安装

请前往 [Releases](https://github.com/你的GitHub用户名/MOSS/releases) 页面，下载最新版本的安装包：

- **Windows**: 下载 `MOSS_x.x.x_x64-setup.exe` 安装包。双击安装即可，无需配置环境。
- **极致轻量**：安装包仅 **2MB+**，摒弃了臃肿的 Chromium 内核，冷启动秒开，内存占用极低。

## ✨ 核心特性

- **🔒 100% 纯本地存储**：没有云端，没有上传。所有图片、笔记、附件均保存在你指定的本地文件夹中，数据完全由你掌控。
- **🗑️ 真实物理删除**：彻底告别“幽灵垃圾”。删除画作时，不仅会清理界面数据，还会**同步彻底删除**本地硬盘上的图片与附件源文件。
- **🖼️ 双视图沉浸体验**：
  - **画廊视图**：四列网格布局，直观展示画作缩略图、标题与彩色标签。
  - **详情视图**：三段式大屏布局（参考图 / 临摹画作 / 笔记），支持沉浸式编辑与查看。
- **🖌️ 画师专属 SAI2 联动**：支持一键导入 `.sai2` 复印件。点击即可另存为并自动唤起本地 SAI2 软件打开原文件。
- **🏷️ 智能标签系统**：支持全局标签颜色自定义、联想输入、点击标签一键过滤相关画作。
- **⚡ 极速响应**：底层基于 Rust 驱动文件操作，内存极低，万张图片轻松管理。

## 📖 操作指南

1. **首次启动**：软件会要求你选择一个**空文件夹**作为“数据仓库”（例如 `D:\MyArtworks`）。该文件夹将用于存放所有原图、配置和数据（`library.json`）。
2. **新建画作**：点击左上角 `+ 新建画作`，进入详情编辑页。
3. **导入内容**：
   - 左侧点击 `+` 导入参考图（支持多选）。
   - 中间点击 `+` 导入临摹画作。
   - 顶部点击 `📎 复印件` 导入 `.sai2` 文件。
4. **编辑与导出**：直接点击标题或笔记即可实时修改；鼠标悬停在图片上，点击 `⤓` 可随时将图片“另存为”导出到桌面。
5. **关于删除**：我们移除了单张图片的“替换/删除”功能，以防产生冗余的本地垃圾文件。**如果你导入了错误的图片，请直接在右上角 `⋯` 菜单中彻底删除该画作，然后重新新建导入即可。**
